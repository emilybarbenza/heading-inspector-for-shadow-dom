Heading Inspector for Shadow DOM

Outlines, lists, and audits every heading on a page, even headings nested deep inside open or closed shadow roots.

Most heading tools stop at the first closed shadow root, because page scripts reading element.shadowRoot get null there. Browser extensions have a privileged API that reaches inside, so this tool uses it. You get an in-place overlay for screenshots, a keyboard-operable outline sidebar, and WCAG-keyed flags for empty headings, skipped levels, and missing or duplicate h1.
